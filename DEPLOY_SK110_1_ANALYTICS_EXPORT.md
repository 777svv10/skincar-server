# SkinCar SK-110.1 — админ-аналитика, себестоимость и CSV

### Два раздельных вида
- Статистика: запуски, успешность, Стандарт/HD/неизвестно, списания/возвраты, токены, модели, Stars, среднее время.
- Себестоимость: USD по модели/качеству, покрытие оценкой, токены, неполные записи, цена по явно заданной серверной тарифной сетке. Это оценка, не счёт OpenAI.

### Периоды
24 часа, 7, 30, 90, 365 дней, всё время. Все даты считаются по серверным меткам UTC, не по часам телефона.
Экспорт — кнопка «📥 Скачать CSV» внутри каждого отчёта или /export_month, /export_year, /export_all (и _today, _week, _quarter).
В CSV каждая генерация: UTC, UUID, модель, статус, Standard/HD/unknown, списание, возврат, токены text/image/output, расчётные USD и версия тарифов, время обработки. Без пользовательского Telegram ID и бинарных изображений.
Безопасность: только BOT_ADMIN_IDS, до 6 скачиваний в час, CSV экранирует опасные формулы. Ограничение 10 000 строк. Неполные файлы не выдаются; для больших объёмов выбирать короткий период.
Старые кнопки /a:today из прошлых сообщений продолжают работать.

### Тарифы
Для Image API /v1/images/edits на 23.11.2026:
- gpt-image-2.5-sunburst: текстовый вход $5/1M, графический вход $8/1M, выход изображения $30/1M.
- gpt-image-2.6-sunburst: то же.
- Источники: https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst, https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst, https://developers.openai.com/api/docs/guides/image-generation
- Не оцениваем запросы без полной разбивки usage, не пытаемся восстановить историческую стоимость из total tokens.
- В отдельном отчёте сверяем 8 Test Generations: $0.45 за 32 079 токенов / 8 запросов, и 45 запросов за 30 дней: 152 538 токенов, в т.ч. text 12 854, image 105 098, output 34 586. По указанным ставкам 45 запросов: ($0.064270+$0.840784+$1.037580)=$1.942634, в среднем $0.04317. Сверять с Billing OpenAI, учесть возвраты/ошибки/другие операции.
