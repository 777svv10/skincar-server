# SkinCar SK-108 — аналитика и оценка расходов OpenAI

База: SK-107, GitHub/Railway. Обновляется только серверная часть.

## Что делает
- Бот: защищённые /cost, /cost_week, /cost_month, /stats, /stats_week, /stats_month. В /admin кнопка «Расходы».
- Сводка последних 24 часов / 7 дней / 30 дней: done, failed, in progress, refunded, режимы HD/Standard/неизвестно, внутренние списания, число запросов с провайдерским usage, входные текстовые/изображения и выходные токены, модели, средняя длительность.
- Параметры читаются из PostgreSQL generations.usage (уже существующая запись ответа OpenAI), model, options.qualityMode, charged_credits и временных меток. Существующие фото, оплаты, кредиты и медиа не затрагиваются.
- Если админ явно указал подтверждённые цены конкретной модели в SKINCAR_IMAGE_RATES_JSON, отображается РАСЧЁТНАЯ USD-сумма только по полностью разложенным на текст/изображения/выход токенам успешных вызовов. Случаи, которые нельзя оценить, считаются отдельно.
- Нет тарифа/usage — нет суммы в USD. Никакой эвристики «tokens * единая цена» нет. Это НЕ реальный инвойс OpenAI.
- До 10 000 строк за период в ответе; при превышении отчёт явно помечается как выборка, а не как полный итог.

## Установка
1. Обнови GitHub main: bot-service.js, image-analytics.js (новый), cost-report.js, sk108-image-analytics.test.js (новый), .env.example, этот документ.
2. Railway получает обновление из GitHub автоматически. Строки в schema.sql НЕ меняются, новые миграции БД не требуются.
3. Переменную BOT_ADMIN_IDS укажи числовыми Telegram ID администраторов. Без неё финансовая статистика для пользователей закрыта.
4. SKINCAR_IMAGE_RATES_JSON по умолчанию не задавай. Только если тарифы конкретной модели сверены по официальному прайс-листу и с фактическим режимом Images API, добавь в Railway:
   {"EXACT_IMAGE_EDIT_MODEL":{"text":<USD за 1M текстовых входных>,"image":<USD за 1M входных изображений>,"output":<USD за 1M выходных>,"version":"approved-YYYY-MM-DD"}}
   Пример JSON — СХЕМА, не реальные ставки. JSON без переносов, числа без кавычек.
5. /admin → «Расходы» или /cost, /cost_week, /cost_month.
6. node cost-report.js — read-only консольный отчёт из окружения Railway (не запускается автоматически).

## Обязательные проверки
- Без BOT_ADMIN_IDS и в групповых чатах отчёт недоступен.
- Без цен USD должен быть «—», не $0 и не выдуманной суммой.
- Старые генерации без разбивки text_tokens / image_tokens не оцениваются.
- Если модель сменилась или тарифы поменялись, старые оценки при повторном отчёте пересчитываются по текущему настроенному тарифу; это НЕ исторически зафиксированная цена.
- Провайдер может списать за незавершившийся у нас запрос; статистика таких расходов без фактического инвойса неполная.
- В USD не включены платежи Stars, курс KZT, комиссия, налоги, Railway, Netlify и прочая инфраструктура.
- Бизнес-задача SK-070 закрыта частично. Исторические тарифы и сверка с OpenAI Billing остаются будущими задачами.
