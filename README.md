# SkinCar — первая настоящая ИИ-примерка

Все файлы архива находятся в корне: распакуйте ZIP на iPhone и загрузите файлы в корень существующего GitHub-репозитория 777svv10/skincar-server с заменой одноимённых. Обязательно добавьте новые app.js и generations.js. Сам ZIP загружать в репозиторий не нужно.

## Порядок обновления

1. Загрузите полный серверный комплект в GitHub. Railway автоматически пересоберёт сервис. Команда запуска npm start; Node.js >=22. PostgreSQL и существующие переменные сохраните.
2. Дождитесь успешного запуска. /health должен вернуть {"ok":true}.
3. Распакуйте SkinCar_Netlify.zip и опубликуйте содержащийся index.html на существующем сайте Netlify.
4. Полностью закройте Mini App и откройте снова через @skincartuning_bot.
5. В профиле появится Telegram ID. Установите в Variables сервиса skincar-server переменную TESTER_TELEGRAM_ID с этим числом. После перезапуска сервиса заново откройте Mini App: аккаунт получит 5 тестовых попыток один раз.
6. Создать → загрузить своё фото → цвет и фактура → Создать образ. Результат сохранится в разделе «Мои ИИ-примерки» гаража.

## Переменные Railway

- BOT_TOKEN — токен SkinCar-бота; уже настроен.
- DATABASE_URL — ссылка на PostgreSQL; уже настроена.
- WEBHOOK_SECRET — случайный секрет от 32 символов; уже настроен.
- APP_URL — https://skincar01.netlify.app/
- OPENAI_API_KEY — ключ OpenAI; уже добавлен. Нужны действующий баланс и доступ к модели.
- TESTER_TELEGRAM_ID — числовой ID единственного тестового аккаунта. Не username.
- IMAGE_EDIT_MODEL — необязательная замена модели. По умолчанию gpt-image-2.5-sunburst.

Секреты не публикуйте в GitHub, HTML или чате. Повторно устанавливать webhook при этом обновлении не требуется.

## Что работает

Проверенный вход Telegram и уникальные ники SkinCar; собственное фото JPEG/PNG/WebP; цвет и фактура кузова; фоновая очередь PostgreSQL; личный гараж; исходник и результат; скачивание; удаление фотографий. Новые таблицы добавляются при запуске без удаления старых профилей.

Попытка списывается атомарно при постановке задания. Повтор одного requestKey не списывает снова. При техническом сбое возврат выполняется один раз. Ключ с другим изображением или параметрами отклоняется. Обработчик не повторяет платные запросы автоматически. После аварийного завершения процесса зависшее задание получает возврат, а не новый вызов OpenAI.

Лимиты пилота: одна активная задача на пользователя, 10 запусков за 24 часа, 20 сохранённых проектов на пользователя, 20 задач в очереди и 200 сохранённых проектов всего. Изображения хранятся в PostgreSQL для пилота, нормализуются и ограничиваются по размеру. Для массового запуска потребуются объектное хранилище, резервные копии, мониторинг и защита от злоупотреблений.

Редактор пока меняет только цвет и фактуру кузова. ИИ может изменить детали или неточно передать оттенок. Это не точная примерка конкретного артикула плёнки. HEIC напрямую не поддерживается.

Оплата, промокоды, баттлы и старые демонстрационные проекты остаются демонстрацией. Клиент не может начислить настоящий баланс. Любая новая реальная генерация расходует средства OpenAI владельца сервиса.

## Проверки

npm ci
npm test

17 автоматических тестов: Telegram-подпись, уникальный ник, повторная отправка, списание/возврат, SQL-очередь, восстановление прерванных задач, доступ владельца, проверка фото, тестовое начисление, формат запроса OpenAI. PostgreSQL в тестах исполняется через PGlite; OpenAI подменён тестовым ответом. Настоящая платная генерация ещё не проверена — это следующий шаг после загрузки обновления.

## Обновление 11 ноября: цвета, диски, свободное задание

Полный комплект загрузите с заменой в GitHub. Новый wheels.json обязателен: содержит три предоставленные карточки и передаёт выбранную картинку модели как дополнительный референс. Все файлы лежат в корне, папки создавать не требуется. Затем обновите index.html на Netlify.

Доступны исходный цвет + белый, чёрный, серебристый, серый, красный, бордовый, оранжевый, жёлтый, зелёный и синий. Покрытия: мат, глянец, сатин. Исходный цвет сохраняет оттенок и меняет фактуру. Диски: исходные, BBS, BMW 128S, Vossen. Названия взяты из пользовательских файлов и не подтверждают точную модель или совместимость с автомобилем.

Свободное задание до 1000 символов: добавление элементов, людей и другие демонстрационные изменения. Выбранные цвет и диски имеют приоритет. Перед редактированием свободный текст проверяется moderation API; при отказе или недоступной проверке генерация возвращается. Правила запроса дополнительно запрещают сексуальный контент и оскорбления. Автоматические фильтры не гарантируют отсутствие всех нежелательных результатов.

Качество: загрузка в браузере до 1400 px по длинной стороне, JPEG quality 0.83. Сервер нормализует исходник JPEG quality 88. Параметр генерации medium. Теперь полученный JPEG сохраняется без дополнительного уменьшения и перекодирования; лимит результата 4 MiB. Превью гаража отдельно 480x320, JPEG75. Кнопка скачивания выдаёт результат, а не превью. Проценты quality не означают процент сохранённой детализации.

19 серверных тестов и сценарий интерфейса прошли. Платная проверка новых дисков и свободных заданий не запускалась. Для 100–200 дисков следует вынести изображения в отдельное хранилище и загружать каталог частями; текущее встраивание трёх PNG предназначено для пилота.

## Отложенные заметки пользователя

- Ограничить смену имени/ника несколькими разами за период. Предложение: 2 раза за 30 дней, точные правила пока не утверждены.
- Кнопка «Палитра»: выбор/ввод HEX-кода, затем применение к кузову, дискам, суппортам и отдельным элементам. Цвет на экране и визуализация не гарантируют точного реального оттенка.
- Пользователь подготовит отдельные кнопки цветов, плёнок, дисков, тюнинга и номеров.
- Поле свободного задания временное, для демонстраций; позже убрать.
- Решение о собственной валюте не принято. Пока используем генерации: один запрос = одна генерация.
