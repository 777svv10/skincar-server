# SkinCar — примерочная и тестовая оплата Stars

## Загрузка с iPhone

1. Распакуйте SkinCar_server_iPhone.zip. Загрузите все файлы из него в корень 777svv10/skincar-server с заменой одноимённых. Сам архив в GitHub не загружайте. Новые payments.js, telegram.js и обновлённый schema.sql обязательны.
2. Дождитесь SUCCESS в Railway. Команда npm start, Node.js >=22. База и старые переменные остаются. Миграции добавляются при запуске без удаления данных.
3. В логах должны быть SkinCar server ready и Stars webhook ready. При временной ошибке Telegram сервер продолжает работать, покупка выключена; настройка webhook повторяется через минуту.
4. Обновите Netlify содержимым SkinCar_Netlify.zip (index.html).
5. Закройте Mini App полностью и откройте заново.

## Путь примерки

Фото из галереи или камеры → название автомобиля → сохранение автомобиля → цвет, покрытие, диски и своё задание → проверка и создание.
Название хранится на сервере в личном гараже, в результате — снимок названия на момент создания. Пока ввод свободный, без выдуманного распознавания марки и модели. Камера через capture=environment: конкретный диалог зависит от Telegram и ОС. Форматы, которые браузер способен прочитать, преобразуются в JPEG; если HEIC не декодируется, пользователь получает предложение выбрать JPG/PNG. Ограничение входа 10 МБ и 40 мегапикселей.
Старые проекты без названия не переименовываются автоматически. Новый автомобиль сохраняется до платного создания образа. До 20 автомобилей на аккаунт. Удаление проектов не удаляет отдельную фотографию автомобиля; удаление данных — через поддержку на текущем пилоте.
В интерфейсе нет ярлыков ИИ. Пояснение о технологии и возможных отличиях есть на финальном экране перед созданием. Название обработчика API и технические комментарии остаются техническими.

## Оплата: что включится после загрузки

По умолчанию PAYMENTS_MODE=pilot. Доступен пакет TEST: 1 генерация за 1 настоящую Telegram Star только аккаунтам 306179287 и 705535713. Это субсидируемая проверка платежей, не коммерческий тариф. Другие пользователи могут пользоваться выданным балансом, но не покупать.
Новые тестировщики: задайте PAYMENT_TESTER_IDS списком Telegram ID через запятую, включая текущие два ID. Например: 306179287,705535713,НОВЫЙ_ID. Переменная заменяет весь список, не добавляет к нему. Никнеймы не используются.
PAYMENTS_MODE=off — выключить новые покупки.
PAYMENTS_MODE=live — открыть предложенные коммерческие пакеты: 1 / 40 Stars, 5 / 175 Stars, 12 / 390 Stars. НЕ включайте live до утверждения цены и проверки фактической себестоимости, вывода вознаграждений, условий для покупателей и реального платежного сценария.
Для Stars не нужен provider token банка. BOT_TOKEN уже настроен. Сервер сохраняет существующий URL webhook и включает message + pre_checkout_query без удаления очереди Telegram.

Сумма и число генераций задаются сервером. Проверяются владелец, валюта XTR, цена и срок счёта. Начисление — только после successful_payment. telegram_payment_charge_id уникален, повторные уведомления не начисляют повторно. callback окна оплаты не является основанием для начисления. История хранится на сервере. /paysupport направляет к @vladisimonn.
Возвраты: оператор внутри окружения сервера запускает node refund-payment.js НОМЕР_ЗАКАЗА для просмотра, затем ту же команду с --confirm для реального возврата Stars. Токены в команду не вставлять. Возвращённые генерации снимаются; при нехватке образуется задолженность, новые генерации заблокированы до пополнения. Повторный возврат уведомления не списывает повторно. Не выполняйте возврат из чужого окружения или без проверки номера заказа.

## Что проверить после публикации

- Сохранить фото и название, перезапустить приложение: автомобиль остаётся в гараже.
- Открыть сохранённый автомобиль, изменить только диски, сохранить цвет и покрытие.
- Проверить итоговый экран и единственное пояснение о технологии.
- У тестировщика: запомнить баланс, открыть TEST, отменить оплату — баланс прежний.
- Оплатить TEST за 1 Star — после подтверждения баланс +1, в истории оплаченный заказ.
- Закрыть и открыть Mini App — баланс и история сохраняются.
- Повторное обновление страницы не даёт ещё +1.
- Проверить /paysupport. Реальный возврат тестового заказа выполнить отдельно с оператором.
- Камеру и выбор HEIC проверить на настоящем iPhone; локальные проверки не заменяют эту проверку.

## Ограничения пилота и качество

1 запуск = 1 генерация. Одна активная задача, 10 запусков за 24 часа, 20 сохранённых проектов на аккаунт, 20 задач в очереди, 200 сохранённых проектов всего. Технические сбои возвращают генерацию один раз. Повторы оплаченных запросов к провайдеру автоматически не делаются.
Картинки пока в PostgreSQL. Для массового запуска требуется вынести их в объектное хранилище, добавить резервирование и мониторинг. Коммерческие пакеты нельзя оценивать только по цене модели.
Источник в браузере: до 1400 px, JPEG .83; нормализация сервера JPEG88; модель gpt-image-2.5-sunburst, medium, size auto. Результат JPEG провайдера сохраняется без повторной компрессии, до 4 MiB. Гараж использует отдельные превью. Диски передаются второй картинкой; точность артикулов и геометрии не гарантируется.
Лимит ника — 2 смены за скользящие 30 дней; первый выбор не учитывается. Палитра HEX пока только для кузова. Баттлы и промокоды не подключены к реальным операциям.

## Себестоимость

Для текущей модели стандартные ставки за 1 млн токенов: текст на входе $5; изображения на входе $8; изображение на выходе $30. Прямой Images API не использует скидку за кэш. Цены проверены 11 ноября 2026:
https://developers.openai.com/api/docs/pricing
https://developers.openai.com/api/docs/guides/image-generation
Цена одного результата не фиксирована: зависит от токенов входных фото, задания, размера и качества. Считать по usage, а не объявлять medium фиксированной ценой.
Пример, НЕ замер SkinCar: 500 текстовых + 2000 входных графических + 5000 выходных токенов = $0.1685.
Telegram указывает эквивалент вознаграждения $0.013 за Star; это не цена покупки Stars пользователем и не гарантированная сумма на банковском счёте:
https://telegram.org/tos/bot-developers#6-2-4-rewards-for-stars
Для 40 Stars ориентир вознаграждения $0.52; для 175 — $2.275; для 390 — $5.07, до остальных расходов. Нужен резерв на сбои, возвраты, хостинг, хранение, поддержку, налоги и расходы получения вознаграждения. Доступность Fragment проверяется владельцем отдельно.
Есть read-only скрипт node cost-report.js: среднее и p90 для последних 100 успешных результатов с полными usage текущей модели. Не учитывает платные сбои и другие расходы. Выполнять внутри окружения сервера. Ключи в аргументы не передавать.

## Следующий этап справочника

Сущности: make → model → generation; пользовательский автомобиль хранит ссылки и исходный введённый текст. Поиск допускает транслитерацию и опечатки. Показывать «Вы имели в виду…?» с подтверждением, не менять название молча. Неизвестные варианты сохранять как неподтверждённые, не создавать из них автоматически публичные марки и рейтинги. Объединение дублей и модерация нужны до запуска статистики.
